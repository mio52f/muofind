# MUO Find

مشروع Android أولي لنظام العثور على الهاتف بمساعدة شبكة أجهزة مشاركة اختيارياً.

## الخيارات المعتمدة
- مشاركة دائمة اختيارية، لا تعمل إلا بعد موافقة المستخدم، مع إشعار واضح وإمكانية الإيقاف.
- خادم مستقل يملكه ويديره صاحب المشروع.
- Bluetooth Low Energy لاكتشاف الأجهزة القريبة عند تطوير مرحلة الاكتشاف.
- تقارير مشفّرة من طرف إلى طرف؛ لا ينبغي أن يتمكن جهاز المساعدة أو الخادم من قراءة محتوى التقرير.
- لا تُرسل هوية مالك الجهاز أو إحداثياته داخل إعلان Bluetooth.

## المرحلة الحالية
هذه المرحلة تجهّز هيكل Android وGitHub Actions فقط. التطبيق الحالي واجهة تأسيسية ولا يجمع الموقع ولا يشغّل Bluetooth ولا يتصل بخادم.

## البناء
يتم البناء على GitHub Actions باستخدام JDK 17 وGradle 8.9 وAndroid SDK 35.
لا يوجد Gradle Wrapper في هذا المستودع عمداً؛ لا يلزم تثبيت Gradle في Termux أو على الهاتف.

بعد رفع الملفات إلى مستودع GitHub:
1. افتح تبويب **Actions**.
2. شغّل **Android CI** عبر **Run workflow**، أو ادفع commit إلى `main`.
3. نزّل artifact باسم `MUO-Find-debug` من نتيجة التشغيل.

## معرّفات المشروع
- Application ID: `com.muo.find.debug` لنسخة Debug.
- Namespace: `com.muo.find`.
- Minimum SDK: 26.
- Target SDK: 35.

## تنبيه أمني
لا تستخدم هذا الإصدار للعثور الفعلي على الأجهزة بعد. بروتوكول التعرّف والتشفير وإدارة المفاتيح يحتاج إلى تنفيذ واختبارات ومراجعة أمنية قبل جمع أي بيانات موقع.
